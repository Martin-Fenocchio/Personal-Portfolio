# First redesign direction

## Intent

This first visual pass moves the portfolio away from a conventional developer-site layout and toward an editorial technical portfolio. The site should feel authored, confident, and human without leaning on familiar neon-AI aesthetics.

## The visual system

- **Foundation:** warm paper and ink black provide the primary contrast.
- **Signal color:** acid green is used for energy, active status, and the work-method section.
- **Supporting accent:** orange gives the system warmth and a selective sense of motion.
- **Typography:** a direct sans-serif does the practical work; an italic serif creates contrast in key phrases only.
- **Structure:** thin rules, small monospaced labels, and a visible grid give the page an editorial technical rhythm.

## Litebox work wall

The Litebox section is intentionally built as an infinite horizontal strip, rather than a static project grid. Each item has a miniature browser bar and a fixed first-viewport frame. It currently uses art-directed placeholders, but each placeholder is a direct replacement point for a real screenshot.

When the sites are ready, add each website as a record with a site name, live URL when it can be public, 16:9 first-viewport screenshot or hero image, and an optional role/technology label.

The duplicated list makes the animation seamless. It pauses for visitors who hover it and stops entirely when the user prefers reduced motion.

## What is intentionally not final

- Page copy and claims
- Specific Litebox client/site names and screenshots
- Project case-study content
- AI teaching/adoption story
- SEO, structured data, and social previews

The layout is designed to accept these pieces without changing the visual direction.
